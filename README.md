# Amara Service Hub

Bilingual (English / Myanmar) services marketplace prototype — browse and book travel, healthcare, beauty, and other local services.

## Contents
- `Amara Reserve.dc.html` — the prototype: home, search/results, service detail pages, multi-package selection, multi-step inquiry flow (add-ons → Terms & Conditions → details), help, and profile screens.
- `_ds/` — shadcn/ui design system tokens and styles the prototype is built on.
- `_theme/theme.css` — project-specific theme overrides.
- `assets/` — logos and static images.
- `image-slot.js`, `support.js` — runtime helpers used by the prototype.
- `screenshots/`, `uploads/` — reference images and design working files.

## Status
Full prototype with bilingual copy (EN/MM, graceful English fallback for untranslated keys) and multi-package selection integrated into the existing inquiry flow.

## Notes
This is a design prototype, not production code. Ask for a Claude Code handoff package for implementation notes (design tokens, interaction spec, state model) when building this into a real app.
